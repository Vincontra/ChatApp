# Java Chat App

A backend-focused chat application built with **Java**.

Currently, the project focuses on building the core backend and understanding client-server communication. The goal is to gradually evolve it into a **full-stack chat application**.

## Tech Stack

* Java
* Socket Programming
* Multithreading
* OOP

## Status

**Backend Development — In Progress**

More features, database integration, and a frontend will be added later.
